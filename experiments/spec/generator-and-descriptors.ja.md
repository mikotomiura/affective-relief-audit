# 正規の生成器と記述子（仕様、第 1 版）—— 確認用の日本語版

正は英語の版 `generator-and-descriptors.md` である。この版は確認のための訳で、食い違えば英語の版に従う。条項の番号は英語の版と同じ。

この文書は、論文のすべての計算（2 次元の K4、端と格子の対応のある比較、公開データでの検証 3、K5）に使う生成器・記述子・処理を定める。計算の前に書いた。`src/atact/` が実装し、`tests/test_spec.py` が条項ごとにコードとの一致を確かめる。

## S1. 手続き的な場

- S1.1 領域と格子: 領域は単位正方形。1 辺 N の格子の点は x_i = x0 + i/N、y_j = y0 + j/N（i, j = 0, …, N − 1）。既定の窓は (x0, y0) = (0, 0)。(x0, y0) をずらすと、同じ無限の場の別の窓になる（切り出しに使う）。
- S1.2 場: F_raw(x, y) = Σ_{o=0}^{O−1} 2^{−o} sin(2π 2^o f x + φ_o) sin(2π 2^o f y + ψ_o)、O = 4。周波数は領域あたりの周期数。配列は [j, i]（行が y）。
- S1.3 位相: 乱数は `numpy.random.default_rng(seed)`。o = 0, …, O − 1 の順に、[0, 2π) の一様乱数を 2 つ引く（先に φ_o、次に ψ_o）。正規の生成器ではそれ以外に乱数を引かない。
- S1.4 正規化: 正規は F = F_raw / 格子の上の max|F_raw|（maxabs）。変種 ampsum は F = F_raw / Σ_o 2^{−o}（定数）で、窓と格子によらず同じ表面になる。同じ表面の窓や格子を比べる計算は ampsum を使う。重心（S2.3）は T_γ の同次性によりこの選択に依らない。
- S1.5 ワープ: 正規の生成器はワープなし。変種として使うときは `atact.field` のもの（仮定 A3）。
- S1.6 周期性: F が領域で周期的になるのは f が整数のときに限る。整数でない f では端で跳ぶ。K4 の「周期化」は整数の f を使うことで、処理の名前ではない。

## S2. 高さと記述子

- S2.1 規則: (V, A) から式 (1)〜(3) で (f, s, γ)（p = (A + 1)/2、q = (1 − V)/2、f = 3 + 4p、s = 0.06 + 0.24q、γ = 0.9 + 1.7(0.65p + 0.35q)、V と A は [−1, 1] に切る）。
- S2.2 高さ: H = s T_γ(F)、T_γ(u) = sign(u)|u|^{1/γ}。なめらかにした版 T_{γ,ε}(u) = u(u² + ε²)^k / (1 + ε²)^k、k = (1/γ − 1)/2。記述子は H − mean(H) で測る。
- S2.3 振幅で重み付けした重心（正規）: C = Σ_k ρ_k |Ĥ_k| / Σ_k |Ĥ_k|。Ĥ は H − mean(H) の 2 次元 DFT、和は N² 個のすべてのビン、k の各成分は `numpy.fft.fftfreq(N) * N`（[−N/2, N/2) の整数）、ρ_k = |k|（ユークリッド）を領域あたりの周期数で。DC は ρ = 0 かつ Ĥ_0 = 0 なので寄与しない。
- S2.4 パワーで重み付けした重心と帯域を固定した重心: パワー重みは S2.3 の |Ĥ| を |Ĥ|² に置き換える。帯域固定は、両方の和を 0 < ρ_k ≤ K のビンに限る（K は領域あたりの周期数で固定、K ≤ N/2）。重みは条件の一部として指定する。
- S2.5 Sq: Sq = sqrt(mean((H − mean H)²))。
- S2.6 最大の傾き: `numpy.gradient(H, 1/N)` による |∇H| の格子の上の最大。
- S2.7 1 次元の重心: 長さ N の z について Σ|k||ẑ_k| / Σ|ẑ_k|（図 4 の 1 次元の行）。
- S2.8 高さから法線の図: 領域の 1 辺 L と同じ長さの単位の z から、傾きを `numpy.gradient(z, L/N)`（中は中心差分、端は片側、周期を仮定しない）で求め、法線 (−∂z/∂x, ∂z/∂y, 1) を正規化し（OpenGL 規約）、round((n + 1)/2 · 255) の uint8 にする。
- S2.9 HF ratio: Gao ら（2026）の公開コードの写し（実行していない）。入力は uint8 の法線の図。境界 `freq_threshold` は画素（既定 120）。規則は 2 つ: px（N によらず 120）と phys（120 N / N_ref。領域あたりの周期数で固定。N_ref は各条件のファイルに書く）。浮動小数の版（対照で、元の指標の一部ではない）: [−1, 1] の浮動小数の法線で、入力と高域通過の後の uint8 への丸めをせずに同じ計算をする。線形の高さの版（命題 8 の 3 の設定の対照）: z − mean(z) の DFT に同じガウス型の高域通過の重みをかけたエネルギーを、DC を除く z − mean(z) のエネルギーで割る。

## S3. 端の処理（比べるためだけのもの）

どれも「真の値」を与えない。

- S3.1 窓: W(i, j) = sin²(πi/N) sin²(πj/N)。X = (H − mean H)W のあと X − mean X。法線の図では、各成分の平均からのずれに同じ W をかけ、正規化し直して uint8 にする。予備の計算 `experiments/hf_ratio_edge.py` は対称の `numpy.hanning` を使っていたが、この仕様で W に改めた。
- S3.2 周期と滑らかの分解（Moisan 2011）: H = p + s、s は端の差の画像を源とする離散のポアソン方程式の解で平均 0。記述子は p で測る。
- S3.3 帯域の固定: K を領域あたりの周期数で決めた S2.4。

## S4. 折り返しの切り分け

- S4.1 高さ H（T_γ の後）を、同じ窓と種で 1 辺 M = rN の細かい格子で作り、各成分が [−N/2, N/2) のビンだけを残す理想的な低域通過（係数 (N/M)²）のあと逆 DFT で 1 辺 N にする。直接 N で標本化したものと記述子を比べる。変換は細かい配列を周期的とみなすので、整数でない f では低域通過が端の跳びにもかかる（報告し、補正しない）。
- S4.2 主の基準はすべての N で r = 2（基準が N とともに変わらないように）。収束の確かめに N ≤ 2048 で r = 4 も使い、r = 2 と 4 の差を基準に残る折り返しとして報告する。N = 4096 で r = 4 を使わないのはメモリのためで、結果では決めていない。
- S4.3 低域通過なしの 1 つおきの間引きは、折り返しを残す対照。

## S5. 実測のデータ

- S5.1 Surface-Topography Challenge（Zenodo 10.5281/zenodo.15341939、記録の単位で CC0）。各コンテナの `-squeezed.nc` の変数 `heights`（NetCDF 3、`scipy.io.netcdf_file` で読む）。単位は `unit` 属性でメートルに直す。物理の長さは `x`・`y` の `length` 属性。
- S5.2 正方形の切り出し: 短い辺を超えない最大の 2 のべき P の中央の P × P。切り出しの後に最小二乗の平面を引く。物理の 1 辺 L = P × 画素の間隔。
- S5.3 格子の段: P × P から P/2 と P/4 を `decimate_fourier`（S4.1）と、対照として `subsample`（S4.3）で作る。物理の領域はすべての段で同じ。
- S5.4 TactileDreamFusion（Hugging Face `Ruihan28/TactileDreamFusion`、revision 87c8b764bcb2ec1139de0c6435f45ac1d9f283d1、MIT）: `normal_patch.png`（240 × 240、alpha は捨てる）と `tiled_normal_map.png` の中央 1024 × 1024。n = rgb/255 · 2 − 1 で復号し、成分ごとに `decimate_fourier`（patch 240 → 120 → 60、tiled 1024 → 512 → 256）、正規化し直して uint8。画素の寸法がデータに無いので、メートルではなく切り出しに対する px と phys の規則だけを使う。

## S6. 条件のファイルに共通の統計

- S6.1 増え方の指数: 種ごとに ln C を ln N に最小二乗で当てた傾き。点の推定は種の平均、95% 区間は種の上の t 区間（自由度 n − 1）。複数のセルにまたがって判定するときは同時区間（Bonferroni、m セルで水準 1 − 0.05/m）を使う。
- S6.2 2 つの表面の順序: 記述子 D と格子の段 g で sign(D_a(g) − D_b(g))（種または切り出しの上の平均。条件のファイルで指定）。段 g と g′ の間の入れ替わりは、符号が変わり、両方の段で平均の差が標準誤差の 2 倍を超える対。種の無い実測では、条件のファイルが相対差の閾値を与える。段の間の順位の Kendall の τ も出す。
- S6.3 環境: 版は `uv.lock` で固定。結果のファイルには条件のファイルとこの文書の SHA-256、numpy の版を書く。
