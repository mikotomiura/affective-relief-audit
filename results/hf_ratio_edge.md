## 読み取り（集計の後に書いた）

- 端の跳び: 同じ表面の切り出しによる幅は 0.001 以下。物理の波長で固定した境界での窓なし − 窓ありは、4 段の場で −0.010〜−0.003、1 段の正弦波（f = 5.5）で +0.036。HF ratio は二乗で重みを付けた比で、法線（傾き）から計算するため、端の跳びの影響は小さい。上の「f5.5 − f5」の差には、端の跳びのほかに模様の周波数の違いが含まれる。
- 格子: 境界が画素数で固定（px120）だと、同じ表面で N = 256 → 2048 に値が 0.955 → 0.460（oct4_f5_g1）。物理の波長で固定（phys）すると 0.671 → 0.695。
- 順序の入れ替わり: px120 で γ 1.75 − 1 の差は N = 256・512 で負、1024・2048 で正（f = 5 と 5.5 の両方、種 5 本のすべてで同じ符号）。phys ではどの格子でも正（f = 5.5 の N = 256 の種 1 本だけ −0.001）。
- Gao ら 2026 の評価は、すべてのモデルを 1024 画素で比べている（公開コードの `01_generate_textures.py` の height = width = 1024、Nano Banana Pro は image_size = "1K"）。この結果は同論文の比較の結論には影響しない。
